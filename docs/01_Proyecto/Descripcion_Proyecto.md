# Descripción de DimaBug

Estado consolidado: 2026-11-09. Aplicación de soporte técnico con conocimiento/soluciones, organización, catálogos, tickets, procedimientos y ejecuciones. Frontend Angular y backend Spring Boot con MySQL; no se utiliza Django.

Actualmente incluye revisiones administrativas de procedimientos, hardware opcional, contratos de ejecución, evidencias fotográficas, correo Gmail API con OAuth independiente del login JWT, materiales y portal público de autoservicio. El chatbot recupera soluciones autorizadas mediante SQL. Los enlaces individuales preparan el uso futuro de NFC/QR; no se han programado ni escaneado etiquetas físicas en esta fase.

Las funcionalidades se acreditan mediante código, pruebas aisladas y comprobaciones locales descritas en cada guía. La aceptación institucional, el despliegue final, UAT integral y certificación de producción siguen pendientes. Las referencias de auditoría del 6 de noviembre describen un checkout anterior.
