# Casos de uso implementados

Referencia 2026-11-09. Los permisos definitivos se comprueban en los servicios y SecurityConfig.

1. Un administrador crea o prepara una revisión editable de un procedimiento, modifica sus pasos y publica. Las ejecuciones anteriores conservan sus contratos y la versión original.
2. Un técnico inicia una ejecución, consulta instrucciones/materiales y completa actividades con las validaciones correspondientes.
3. El técnico envía una solicitud de evidencias, registra manualmente fotografías recibidas y aprueba o rechaza. El rechazo conserva archivos; una nueva ronda requiere la acción explícita del formulario actualizado.
4. Un administrador vincula una cuenta Gmail mediante state/PKCE. JWT sigue autenticando al usuario. Autorizar una cuenta no habilita por sí solo los envíos reales.
5. Una persona anónima busca una solución pública o abre su URL individual. La API verifica el estado del padre, de la solución y de cada material.
6. El chatbot consulta fuentes de autoservicio autorizadas, sin mostrar campos administrativos.
7. Un administrador copia la ruta individual de una solución elegible; podrá usar su URL absoluta en NFC/QR cuando configure el despliegue. No se elige una solución por asumir relación uno a uno con conocimiento.

Escaneos NFC reales, recuperación de contraseña operativa y aprobación institucional siguen pendientes.
