# Requisitos funcionales reconstruidos

Referencia 2026-11-09. Este documento refleja código y solicitudes de implementación; no constituye un catálogo institucional aprobado.

| Función | Implementación actual | Límite |
|---|---|---|
| Identidad y roles | JWT y permisos backend | Recuperación de contraseña incompleta |
| Conocimiento/soluciones | Estados, autoservicio y asignaciones | Contenido público requiere revisión editorial |
| Tickets | Flujos y adjuntos por caso de uso | Validación integral de producción pendiente |
| Procedimientos | Edición administrativa, revisiones y hardware opcional | Conservar la revisión usada por cada ejecución |
| Ejecución | Contrato de pasos, criticidad, progreso e historial | No acreditar actividad física mediante correo aceptado |
| Evidencias | Carga manual, revisión, aprobación/rechazo y rondas | No lectura automática de adjuntos Gmail |
| Comunicaciones | SIMULADO/SMTP/Gmail API con auditoría e idempotencia | Real requiere configuración y habilitación explícitas |
| Autoservicio | API y portal públicos, materiales con autorización individual | Solo activa + autoservicio + padre publicado |
| Chatbot | Recuperación SQL de soluciones elegibles | No IA generativa externa |
| NFC/QR | Ruta estable por solución y copiar enlace | Sin hardware/etiquetas programadas |

Las pruebas de cada función se referencian en resultados QA y guías de implementación.
