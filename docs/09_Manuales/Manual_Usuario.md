# Manual de usuario

## Autoservicio sin sesión

Abrir `/autoservicio` para buscar soluciones o `/chatbot` para consultar al asistente. El enlace individual `/autoservicio/soluciones/:id` muestra instrucciones y materiales autorizados. Recursos no publicados/inexistentes muestran no disponible; no se habilitan controles administrativos.

## Administración de soluciones

Con rol administrador, abrir `/soluciones`. El interruptor AUTOSERVICIO confirma cambios con el backend y no habilita soluciones inactivas. El conocimiento padre también debe estar publicado para acceso anónimo.

En el detalle se agregan materiales mediante el formulario compartido. Cada archivo/enlace necesita autorización individual para publicación; revisar su contenido y los permisos del proveedor. La sección NFC/QR permite copiar la ruta individual y configurar posteriormente una base accesible. Sin base se identifica como ruta de prueba. No programa etiquetas físicas.

## Procedimientos y ejecución

El administrador usa Editar procedimiento para preparar una revisión; puede gestionar datos, hardware y pasos. Las ejecuciones previas conservan su versión. El técnico consulta instrucciones y materiales incluso en pasos completados; abrir un recurso no cambia el progreso.

Para solicitar evidencias: preparar destinatarios Para/CC y contenido, enviar una vez, adjuntar las fotos recibidas y registrar recepción. Revisar y aprobar explícitamente los pasos críticos. Rechazar exige motivo y conserva evidencia; Solicitar nuevamente crea otra ronda por acción explícita. La aceptación de correo no acredita recepción de fotos ni trabajo físico realizado.

## Gmail

Administración → Conexión Gmail permite ver estado, autorizar y revocar con confirmación. La prueba administrativa es independiente de procedimientos y requiere habilitación/confirmación reales; no usar ejecuciones nuevas para probar transporte. SIMULADO no envía correos.

## Otras funciones y límites

Los permisos de tickets y operaciones dependen del rol/caso de uso, no solo del menú. Reportes demostrativos, Nuevo error local, favoritos/avisos locales y recuperación de contraseña incompleta no se presentan como servicios remotos operativos completos.
